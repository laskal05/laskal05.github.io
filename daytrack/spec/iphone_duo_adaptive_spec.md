# iPhone Duo & 大画面アダプティブUI仕様書 (iPhone Duo Adaptive Spec)

## 1. 概要
iPhone Duo（外側5.4インチ / 展開時7.6インチ）をはじめとする折りたたみ端末（フォルダブル）および大画面端末（iPad/タブレット）において、大画面の作業領域を最大限に活用するための「アダプティブ2ペイン表示（大画面・一覧性最適化）」の仕様を定義します。

## 2. デバイス検出とブレークポイント
*   **判定基準 (Breakpoint)**:
    *   画面幅（`MediaQuery.of(context).size.width`）が **600dp以上** の場合を「ワイド画面（iPhone Duo展開時 / 大画面モード）」と判定する。
    *   画面幅が **600dp未満** の場合は、従来のスマートフォン用シングルペイン表示（カバー画面モード）とする。
*   **ヒンジ / 折り目の配慮 (Display Features)**:
    *   `MediaQuery.of(context).displayFeatures` にヒンジ（`DisplayFeatureType.hinge` または `DisplayFeatureType.fold`）が存在する場合、コンテンツが折り目と重ならないように分割位置やパディングを考慮する。

## 3. 画面ごとのアダプティブ仕様

### 3.1. カレンダー画面 (`CalendarScreen`)
*   **シングルペイン時 (幅 < 600dp)**:
    *   従来のレイアウトを維持（月移動ヘッダー ＋ 連勝バナー ＋ カレンダーグリッド ＋ 月間推移グラフ ＋ 下部合計/追加ボタン）。
    *   日付セルタップ時は `AmountInputScreen` へ全画面遷移。
*   **ワイド画面時 (幅 >= 600dp / 2ペイン)**:
    *   左右分割（左側約 50% / 右側約 50%）のレイアウト。
    *   **左ペイン**:
        *   月移動ヘッダー (`MonthTransitWidget`)
        *   連勝バナー (`_buildStreakBanner`)
        *   カレンダーグリッド (`PageView.builder`)
        *   下部合計パネル
    *   **右ペイン**:
        *   **選択日の詳細カード (DayDetailCard)**:
            *   カレンダーで選択された日付の損益、勝敗、取引メモ、登録画像、タグ・トレード条件を表示。
            *   「編集」「新規入力」「削除」ボタンをインラインで配置し、タップですぐに編集可能。
            *   日付未選択時は当日のデータをデフォルト表示。
        *   **月間損益推移グラフ (`MonthlyProfitLossChart`)**:
            *   選択日詳細カードの下部に配置し、月全体の推移も常時一目で確認可能。

### 3.2. 分析画面 (`StatsScreen`)
*   **シングルペイン時 (幅 < 600dp)**:
    *   従来の縦スクロール（期間選択、サマリーカード、累積損益グラフ、年間成績、相関分析）。
*   **ワイド画面時 (幅 >= 600dp / 2ペイン)**:
    *   **左ペイン**:
        *   期間選択セグメントコントローラー
        *   パフォーマンスサマリー（勝率、損益額、プロフィットファクターなど）
        *   累積損益グラフ
    *   **右ペイン**:
        *   年間成績一覧カード
        *   トレード条件・タグ相関分析カード

### 3.3. ホーム画面 (`HomeTabScreen`)
*   **シングルペイン時 (幅 < 600dp)**:
    *   従来の縦スクロール（累計記録、本日のアクション、今週の成績グラフ、AI診断パネル）。
*   **ワイド画面時 (幅 >= 600dp / 2ペイン)**:
    *   **左ペイン**:
        *   累計記録バッジ
        *   本日のアクション（記録ボタン・ステータス）
        *   今週の成績グラフ
    *   **右ペイン**:
        *   AI診断レポート（負けパターン分析・改善アドバイス）
        *   直近の取引一覧（クイック確認）

## 4. UIデザイン・レイアウト規約遵守
*   `docs/spec/design_system.md` のルールを厳格に遵守する。
*   `CupertinoPageScaffold` の背景色は `primaryColor`、`SafeArea` 直下のコンテナ背景色は `AppColors.background` を使用する。
*   2ペイン分割時も各ペイン内のカード背景には `AppColors.card`、境界線には `AppColors.border` を用い、ダークモード/ライトモードで統一感を保つ。
*   テキストやアイコンの視認性（コントラスト比）を維持する。
