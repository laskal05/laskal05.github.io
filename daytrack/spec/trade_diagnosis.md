# トレード診断（明日への一言）仕様書

## 1. 役割と他画面との棲み分け
*   **分析タブ (`StatsScreen`)**: 期間全体の静的集計・グラフ・手法×コンディションのヒートマップを担当。
*   **ホーム画面「今週の成績」**: 今週（月〜金）の短期スナップショットを担当。
*   **ホーム画面「明日への一言」(`TradeDiagnosisPanel`)**:
    *   トレード前後（寄り前・大引け後）にパッと見て、次のトレードのスタンスを決めるための**タイムリーで行動に結びつく事実**を1〜2個に絞って提示する。
    *   全期間の勝率やPFの単なる羅列は行わず、「直近の流れ・明日の曜日・コンディション差・損失バランス」などの気づきに特化する。

## 2. 表現ガイドライン（断定禁止）
*   投資助言・断定的表現を避け、**客観的な記録の事実**と**穏やかな参考提案**に留める。
*   **許容される語尾例**: 「〜の傾向が見られます」「〜を意識してみてもよいかもしれません」「〜も一つの選択肢です」「〜という記録があります」
*   **禁止する表現例**: 「〜すべきです」「必ず〜してください」「〜すれば勝てます」「〜が正解です」

## 3. 診断ロジック（`LocalSqliteAnalysisService`）
対象データは直近90日分（`amount == 0` のノートレ日は勝率・平均損益の分母から除外する）。
以下の優先順位で事実を抽出し、**最大2つ**までの具体的な根拠（`privateMessage`）と**1行の結論**（`publicMessage`）を生成する。

### 3-1. 記録が少ない場合（勝敗のあるトレードが5件未満）
*   警告なし（`hasWarning: false`）として、現在の記録日数と「5日分以上の記録が溜まると傾向が見えやすくなります」といった案内を表示する。

### 3-2. 注意喚起パターン（`hasWarning: true`）
1.  **直近のトレードが大勝だった翌日ジンクス**（最新記録が大勝 ＆ 過去の大勝翌日の負け率50%以上・2回以上）
2.  **連敗ストッパー**（直近2連敗以上している場合：連敗数と合計損失額を事実として提示）
3.  **明日の曜日の勝率低下**（明日が平日かつ過去90日で該当曜日の勝率40%未満・3回以上）
4.  **コツコツドカン傾向**（勝敗4件以上で、平均損失 > 平均利益 × 1.2 かつ 勝率50%以上、または平均損失 > 平均利益 × 1.5）
5.  **コンディション別ギャップ**（「感情的・ルール破り」の負け記録が2件以上あり、かつ「冷静・ルール通り」より勝率が低い場合）
6.  **ネガティブ感情タグでの損失**（過去90日で該当タグ付きの負けが2回以上）

### 3-3. 好調・通常時の事実提示（`hasWarning: false`）
定型文（「目立った負けパターンは見当たらないよ」のみ）は使わず、以下の事実から見つかったものを1〜2個提示する。
1.  **連勝中の事実**（直近2連勝以上：連勝数と合計利益）
2.  **明日の曜日の好調傾向**（明日の曜日の勝率60%以上・3回以上）
3.  **好調な手法・タグ**（直近90日で2回以上かつ累計プラスの最高利益タグ）
4.  **冷静トレードの実績**（`TradeCondition.good` の勝率・件数）
5.  **上記に当てはまらない場合でも直近の勝敗・平均損益の事実**を1つ添える

## 4. UI設計（`TradeDiagnosisPanel`）
*   **上段（常時表示）**: ヘッダー（アイコン＋「明日への一言」＋AIバッジ）と、`publicMessage`（1行の結論）。
*   **下段（根拠となる事実）**: `privateMessage` を箇条書きベースで見やすく表示（`hasWarning == true` かつ無料ユーザー未解放時は従来通りロック表示）。
*   `design_system.md` の `AppColors` ルールを厳守する。
