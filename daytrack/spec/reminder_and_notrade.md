# 入力リマインダー通知 ＆ ノートレ日ワンタップ記録 仕様書

## 1. 入力リマインダー通知

### 1.1 概要
日々のトレード収支の記録忘れを防ぎ、継続率を高めるためのローカル通知機能。外部サーバーやAPIは使用せず、端末内のローカルスケジュール（`flutter_local_notifications`）のみで完結する。

### 1.2 設定項目（`ReminderSettingsController`）
`SharedPreferences` に以下の設定を保存する。
*   `input_reminder_enabled` (bool): リマインダーのON/OFF（デフォルト: `false`）
*   `input_reminder_hour` (int): 通知時刻の時（0〜23、デフォルト: `21`）
*   `input_reminder_minute` (int): 通知時刻の分（0〜59、デフォルト: `0`）
*   `input_reminder_weekdays_only` (bool): 平日のみ通知するか（土日を除外、デフォルト: `true`）

### 1.3 スケジュール制御ルール（スマート・リスケジュール）
*   **予約通知ID**: `200` 〜 `206`（直近7日分）をリマインダー用として使用する。
*   **当日記録済みスキップ**:
    *   スケジュール同期時、`DatabaseHelper` から本日のエントリー有無を確認する。
    *   すでに本日の記録が存在する場合（ノートレ記録含む）、本日の通知はスケジュール対象から除外し、翌日以降の該当曜日のみスケジュールする。
    *   本日の指定時刻をすでに過ぎている場合も、本日の通知はスキップする。
*   **平日フィルタ**:
    *   `weekdaysOnly == true` の場合、土曜日（`DateTime.saturday`）・日曜日（`DateTime.sunday`）はスケジュール対象から除外する。
*   **同期タイミング**:
    1. アプリ起動時（`main.dart`）
    2. 通知設定の変更時（ON/OFF、時刻、平日のみ設定）
    3. DB更新時（`DatabaseHelper.instance.onDatabaseUpdated` 購読、または収支の追加・編集・削除時）
*   **通知文言**:
    *   タイトル: `今日のトレード収支を記録しましょう`
    *   本文: `1日の振り返りをDayTrackに残しませんか？（ノートレ日もワンタップで記録できます）`

### 1.4 画面・UI仕様
*   **設定画面 (`SettingsScreen`)**:
    *   「アプリ設定」セクション内に「通知設定」行を表示する。
    *   サブタイトルに現在のリマインダー状態（例：`OFF` または `毎日 21:00` / `平日 21:00`）を表示する。
*   **通知設定画面 (`NotificationSettingsScreen`)**:
    *   `design_system.md` の `CupertinoPageScaffold` / `AppColors` ルールを厳守する。
    *   「入力リマインダー」セクションを配置し、以下を提供する。
        *   リマインダー通知 ON/OFF スイッチ（ON時にOSの通知権限をリクエストし、未許可の場合はエラートーストを表示してOFFに戻す）
        *   通知時刻行（有効時に表示・タップで `CupertinoDatePicker(mode: CupertinoDatePickerMode.time)` のモーダルを表示）
        *   「平日のみ通知（土日を除く）」スイッチ（有効時に表示）
    *   保留中の「相場通知（日経平均先物）」セクションは非表示とする。

## 2. 「ノートレ日」のワンタップ記録

### 2.1 データ仕様（後方互換性）
*   データベーススキーマ（`entries` テーブル）は変更しない。
*   ノートレ日として以下の値を `upsertEntry` で保存する。
    *   `profit`: `0`
    *   `loss`: `0`
    *   `amount`: `0`
    *   `description`: `'ノートレ'`
    *   `condition`: `null`
    *   `tags`: `const []`
*   `TradeLogic.calculateWinRate` により `amount == 0` は勝率計算の分母に含まれない。
*   `ShareCardGenerator` の「0円時の無彩色ルール」により、カード上はニュートラルな色・`¥0` で描画される。

### 2.2 UI導線
*   **ホーム画面 (`HomeTabScreen`)**:
    *   「今日のアクション」が未記録（`todayEntry == null`）のとき、メインボタン「今日の収支を記録する」の下にサブボタン「今日はノートレを記録」を配置する。
    *   `CupertinoButton` テキスト視認性ルールに従い、文字色を明示的に指定する。
    *   タップ時、確認なしで即座に本日のノートレを保存し、トースト（「本日のノートレを記録しました」）を表示する。
*   **カレンダー画面 (`CalendarScreen` / `CalendarDayDetailCard`)**:
    *   未記録の日付を選択している場合、詳細カード内に「ノートレを記録」ボタンを配置し、同様にワンタップで記録できるようにする。
*   **修正・削除**:
    *   記録後は通常のエントリーと同様に「修正する」から金額入力画面を開き、数値の入力や削除が可能。
