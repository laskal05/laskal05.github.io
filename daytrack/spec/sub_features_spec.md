# サブ機能仕様書 (Sub Features Spec)

## 1. 概要
メイン画面には表示しない、独立した「サブ機能」群を定義します。
サブ機能へのアクセスは、「設定」画面内に新設する「サブ機能」セクションから行います。

## 2. 設定画面の変更
`lib/presentation/setting_screen.dart` の「その他」セクションの上に、新たに「サブ機能」セクションを追加します。

*   **セクションヘッダー**: `_SectionHeader('サブ機能')`
*   **項目**:
    *   **タイトル**: ポモドーロタイマー
    *   **アイコン**: `CupertinoIcons.timer` (色は `CupertinoColors.systemRed` など)
    *   **タップ時の動作**: `PomodoroScreen` への遷移

## 3. ポモドーロタイマー (PomodoroScreen)
集中力維持のためのシンプルなポモドーロタイマー機能です。

### 3.1. 基本仕様
*   **作業時間**: デフォルト 25分（ユーザーが自由に変更可能）
*   **休憩時間**: デフォルト 5分（ユーザーが自由に変更可能）
*   **状態**: 待機中 (Initial) / 作業中 (Work) / 休憩中 (Break) / 一時停止 (Paused)

### 3.2. 画面レイアウト (`lib/presentation/sub_features/pomodoro_screen.dart`)
`docs/spec/design_system.md` の基本構造に従い、以下のレイアウトを構築します。

*   **NavigationBar**: 
    *   戻るボタン
    *   タイトル: "ポモドーロ"
*   **コンテンツ**:
    *   **状態・時間表示とUI**:
        *   時間表示の周囲に「円形のプログレスバー (CircularProgressIndicator)」を配置。
        *   時間表示の下にスライダー (`CupertinoSlider`) および「クイックプリセットボタン」を配置。
    *   **セッション管理と目標**:
        *   集中完了時に自動で休憩へ遷移・スタートし、その日の完了回数（🍅）を記録・表示。
        *   **大休憩（Long Break）**: 集中を4回完了するごとに、通常の休憩の代わりに長い休憩（例: 15分）を自動セット。
        *   **1日の目標セット**: 目標回数（例: 6回）に対する進捗を表示し、状況に応じた「応援メッセージ」を表示。
    *   **集中サポート機能**:
        *   **環境音（ホワイトノイズ）再生**: 集中タイム中のみ、カフェ音や雨音などのBGMを再生できる機能。
        *   **スマホ伏せスタート＆離脱警告**: 近接/加速度センサーを利用し、スマホを伏せると自動スタート。集中中に別アプリを開いた場合、警告通知を送信。
    *   **コントロールとフィードバック**:
        *   各種操作時およびタイマー終了時に `HapticFeedback` による触覚フィードバックを提供。
        *   タイマー終了時にローカル通知でバックグラウンドアラームを送信。
        *   **中断防止（Give upプロテクション）**: 集中タイム中に停止・リセットしようとした際、確認ダイアログを表示して安易な中断を防止。

### 3.3. 状態管理
タイマーのカウントダウンロジックは、StatefulWidget 内での `Timer` クラスの使用、またはプロバイダー（`ChangeNotifier`）を使用した状態管理のいずれかで行います。シンプルなサブ機能であるため、まずは StatefulWidget 内での実装を基本とします。

### 3.4. 通知 (将来の拡張)
バックグラウンドでの通知や、タイマー終了時のアラートについては、必要に応じて通知機能（`flutter_local_notifications`）と連携させることを検討します。初期段階では画面を開いている状態でのアラート表示（音バイブレーション、またはダイアログ）とします。

## 4. 息抜きミニゲーム：デイトレ・テトリス (TetrisScreen)
トレードや検証の合間に、頭を切り替えるための息抜きミニゲームとして、トレード要素を取り入れたテトリスを実装します。

### 4.1. 基本仕様とトレード要素
*   **ボードサイズ**: 10列 x 20行の標準的なグリッド。
*   **ブロック (テトリミノ)**: 7種類 (I, J, L, O, S, T, Z)。
*   **スコア＝利益 (Take Profit)**: 行を消去するとスコアが「+¥10,000」のように日本円（利益）として加算される。
*   **損切り (Cut Loss) システム**: 専用の「損切り」ボタンをタップすると、現在落下中のブロックを破棄できる。代償としてスコア（資金）が一定額マイナスされる。
*   **相場環境 (ボラティリティ) 変化**: 一定時間または一定ブロックごとに、ランダムで落下スピードが変化する。
    *   `経済指標発表`：一定時間、超高速落下になるパニックモード。
    *   `レンジ相場`：スピードがゆっくりになるボーナスタイム。
*   **ゲームオーバー＝強制退場 (ロスカット)**: ブロックが一番上まで積み上がるとゲーム終了。

### 4.2. 画面レイアウト (`lib/presentation/sub_features/tetris_screen.dart`)
`docs/spec/design_system.md` の基本構造に従い、以下のレイアウトを構築します。

*   **NavigationBar**:
    *   戻るボタン
    *   タイトル: "息抜きテトリス"
*   **コンテンツ**:
    *   **ヘッダー情報領域**:
        *   現在の利益（スコア）と相場環境（現在のスピード状態）を表示。
        *   次に落ちてくるブロック (Next) のプレビュー。
    *   **ゲームボード領域**:
        *   `CustomPaint` などを用いてグリッドとブロックを描画。
        *   ゲームオーバー時には「強制退場 (Game Over)」テキストと「リトライ」ボタンをオーバーレイ表示。
    *   **コントロールボタン群**:
        *   画面下部にボタンを配置。
        *   【左移動】【右移動】【回転(Rotate)】【下(ソフトドロップ)】【一気に落とす(ハードドロップ)】【損切り(Cut Loss)】

### 4.3. 状態管理とロジック
*   **状態・ロジック分離**: ゲームの内部状態（盤面配列、現在落下中のブロック座標、スコア、相場環境タイマー等）を管理するクラス（例: `TetrisGame`）を作成し、UI（Widget）とは分離する。
*   **ゲームループ**: `StatefulWidget` の `initState` で `Timer.periodic` を開始し、現在の「相場環境（スピード）」に応じた間隔で状態を更新し描画する。
